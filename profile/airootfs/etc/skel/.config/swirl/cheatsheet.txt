  SweetPotato — keybinds
  Mod = Super / Windows key

  This page
  x                    Keybind reminder

  Apps
  Mod+Space          App launcher (Esc closes it)
  Mod+Return         Terminal (foot, fish)
  Mod+w              Web browser (Brave Origin)
  Mod+f              Files (Thunar)
  Mod+e              Editor (Geany)
  Mod+r              Music / radio (Spore)
  Mod+t              Torrents (tuber)
  Mod+n              Network (Wi‑Fi)
  Mod+i              Installer (live ISO)

  Window / layout
  Mod+q              Close window
  Mod+m              Toggle column 100% ↔ 50%
  Mod+Shift+f        Fullscreen
  Mod+a              Floating toggle
  Mod+b / Mod+v      Split horizontal / vertical
  Mod+Shift+a        Focus parent
  Mod+h/j/k          Focus left / down / up
  Mod+Left/Right     Focus left / right
  Mod+Shift+hjkl     Move window (vim keys)
  Mod+Shift+arrows   Move window
  Mod+drag           Move floating window
  Mod+right-drag     Resize floating window

  Workspaces / overview
  Mod+Tab            Overview (stacked desktops, all windows)
  click              Zoom back in (focus that window/desktop)
  Mod+Up/Down        Workspace above / below (exits overview)
  Mod+Ctrl+Up/Down   Move window to workspace above / below
  Mod+1…0            Workspace 1–10 (exits overview)
  Mod+Shift+1…0      Move window to workspace 1–10

  Displays / look
  Mod+Ctrl+w         Wallpaper
  Mod+Ctrl+t         SweetPotato themer
  Mod+Ctrl+g         Corners and gaps
  Mod+Ctrl+d         Displays (nwg-displays)

  System
  Mod+l              Lock
  Mod+c              Caffeine (idle lock off)
  Mod+Ctrl+b         Smart Brightness (toggle)
  Mod+Shift+c        Reload config
  Mod+Shift+e        Exit Swirl
  Mod+o / Mod+Esc    Power menu
  Mod+Shift+r        Resize mode
  Mod+?              This cheatsheet (toggle)

  Screenshots / media keys
  Print              Screenshot (full)
  Mod+Shift+Print    Screenshot (region)
  Mod+Print          Screen record toggle
  XF86 audio keys    Volume / mute / mic / media
  XF86 brightness    Brightness up / down
  Smart Brightness   Max backlight for fullscreen video (on by default)

  Gestures
  3-finger L/R       Scroll the window strip
  4-finger up/down   Next / previous workspace

  Resize mode (after Mod+Shift+r)
  hjkl or arrows     Resize focused window
  Enter / Esc        Leave resize mode

  Customize
  Edit ~/.config/swirl/config.d/user then Mod+Shift+c
  (survives updates; later binds win over defaults)

  Desktop / package updates
  sudo sweetpotatos-update
  A notice once a week when updates are ready
  After an update, a note says what changed

  Project
  w                    Open project website
