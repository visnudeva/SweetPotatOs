  SweetPotato — keybinds
  Mod = Super / Windows key

  Apps
  Mod+Space          App launcher
  Mod+Return         Terminal (foot)
  Mod+w              Web browser
  Mod+f              Files
  Mod+e              Editor
  Mod+r              Music / radio (Spore)
  Mod+n              Network (Wi‑Fi)
  Mod+i              Installer (live ISO)

  Window / layout
  Mod+q              Close window
  Mod+m              Expand column ↔ 50/50
  Mod+Shift+f        Fullscreen
  Mod+Shift+space    Floating toggle
  Mod+b / Mod+v      Split horizontal / vertical
  Mod+a              Focus parent
  Mod+h/j/k          Focus left / down / up
  Mod+Left/Right     Focus left / right
  Mod+Shift+hjkl     Move window (vim keys)
  Mod+Shift+arrows   Move window
  Mod+drag           Move floating window
  Mod+right-drag     Resize floating window

  Workspaces / overview
  Mod+Tab            Workspace overview (all desktops)
  Mod+Shift+Tab      Overview (current desktop)
  click              Zoom back in (focus that window/desktop)
  Mod+Up / Down      Switch workspace (exits overview)
  Mod+Ctrl+Up/Down   Move window to workspace
  Mod+1…0            Workspace 1–10 (exits overview)
  Mod+Shift+1…0      Move window to workspace 1–10

  Displays / look
  Mod+Shift+w        Wallpaper
  Mod+Shift+d        Displays (nwg-displays)
  Mod+Ctrl+d         Save display layout

  System
  Mod+l              Lock
  Mod+c              Caffeine (idle lock off)
  Mod+Shift+c        Reload config
  Mod+Shift+e        Exit Swirl
  Mod+o              Power off
  Mod+Shift+r        Resize mode
  Mod+?              This cheatsheet (toggle)

  Screenshots / media keys
  Print              Screenshot (full)
  Mod+Shift+Print    Screenshot (region)
  Mod+Print          Screen record toggle
  XF86 audio keys    Volume / mute / mic / media
  XF86 brightness    Brightness up / down

  Gestures
  3-finger L/R       Scroll the window strip
  4-finger up/down   Next / previous workspace

  Resize mode (after Mod+Shift+r)
  hjkl or arrows     Resize focused window
  Enter / Esc        Leave resize mode
