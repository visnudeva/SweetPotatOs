Fourth Harvest

Planned ISO 1 November 2026 · Desktop changes already on the sweetpotatos-update channel for Third Harvest installs

  • New wallpapers are in the picker (Mod+Shift+w). New installs start on NewSpoNeon. The wallpaper already on your PC stays, including any older ones you still have.
  • The boot splash uses the new white logo.
  • An update keeps the color theme you picked. It no longer snaps back to Sweet potato.
  • Brave uses the same window frame as the other apps. It no longer draws its own rounded corners. Quit Brave and open it again after updating.
  • Two wallpapers were added: SpoKawai and Spo3d. Open the wallpaper picker with Mod+Shift+w. The wallpaper you are using stays as it is.
  • When two or more windows are open, an 8px gap shows the wallpaper around each one. The space between them is 16px. A single window stays edge to edge.
  • In Spore, the first favorite lines up with the others. The first file on the Files tab and the search line on Radio do too. Quit Spore and open it again after updating.
  • The thin border around windows such as foot is slightly rounded (8 pixels). Shadows stay off. Apps that draw their own title bar, such as Thunar, stay square. Close and reopen a window after updating to see the curve.
  • Mod+Shift+t cycles color themes on the current surface. Mod+Ctrl+t switches between the dark set (Sweet potato, Ube, Lime, Monochrome) and the light set (Dragon fruit, Sweet potato, Blueberry, Monochrome). The bar, Thunar, foot, notifications, the lock screen, and fastfetch follow the theme. On light themes the tray icons are dark, and Thunar’s file list and menu bar use the same off-white as the bar. The Places selection uses the theme accent. Geany stays on its dark editor. Tuber and Spore follow the theme the next time they open.
  • The status line uses icons for CPU, memory, disk, brightness, battery, volume, and Wi-Fi. The percentages stay. Volume sits after brightness, and the battery sits just before Wi-Fi. The window title, the Wi-Fi name, and the date stay as text. The tray icons after the clock sit closer together. Opening the app menu (Mod+Space) no longer leaves a white pixel from the status line under the app names.
  • The power-off confirmation (Mod+Escape or Mod+O) stays above the status bar. Open windows do not slide up under the yellow bar, including when you switch to an empty workspace. Pressing the shortcut again does not open a second bar.
  • When a workspace has no window, the label next to the CPU percentage is just that workspace’s number. The dots on the left of the bar stay.
  • Workspace numbers on the bar are dots. Other workspaces are SPO orange; the one you are on is SPO pink. Mod+1…0 still switch workspaces.
  • A desktop notice once a week when SweetPotatOs packages are ready to install or upgrade (Monday morning, or the next time the machine is on). A missed notice shows once at login. Apply them with sudo sweetpotatos-update.
  • After sudo sweetpotatos-update installs or upgrades packages, a desktop note titled SweetPotatOs updated says what changed. The same text is printed in the terminal.
  • Tuber picks up .torrent files in ~/Downloads and magnet links on the clipboard while it is open. The status line says where the torrent came from, then after a few seconds shows the name of the torrent under the cursor.
  • Wipe (w) deletes the download and the .torrent in Downloads. A wiped torrent stays off the list on the next launch, including when its magnet is still on the clipboard. Saving that .torrent file into Downloads again starts it.
  • swaylock-effects replaces stock swaylock, keeping the SweetPotato charcoal / orange / pink lock theme and adding a lock-screen clock and date (larger bold SPO-pink text).
  • Mod+? floating help cheatsheet (~50% × 90%, centered): SPO colors, opens at the top of the sheet, w opens the project website, and a Desktop / package updates line for sudo sweetpotatos-update.
  • Login tip now says Mod+? — keybinds & project links.
  • sudo sweetpotatos-update alone is enough: it upgrades packages, refreshes shipped config, reloads Swirl, and does not require Mod+Shift+c.
  • Project site: contact form on sweetpotatos.sourceforge.io (email used only to reply).

Third Harvest

Released 24 September 2026 · ISO Sweetpotatos_2026.10_Third_Harvest.iso · Files folder 2026.10_Third_Harvest

  • Tuber replaced Transmission for torrents (Mod+t) — light terminal BitTorrent client; magnet clicks hand off to the open session. Existing installs pick it up with sweetpotatos-update once the package is on the channel (Transmission is replaced).
  • Brave Origin became the default browser (Mod+w), replacing Firefox on new installs.
  • Mod+Tab workspace overview (all desktops); hold Super and drag windows between them. Plain click zooms back in.
  • Mod+Shift+Tab overview of windows on the current desktop.
  • Mod+? floating keybind cheatsheet (toggle), with a login tip that points at it every session.
  • Mod+a floating toggle.
  • Mod+Escape (same as Mod+o) power off.
  • Mod+Up / Mod+Down follow the visual stack (higher workspaces sit below).
  • Default wallpaper is SpoNeon (neon tuber art); UsefulBinds / BindsBG are no longer shipped. sweetpotatos-update also refreshes shipped wallpapers into ~/Pictures/Wallpapers without changing your active waypaper choice.
  • Spore ships a few default favorite radio stations on first launch (SomaFM Groove Salad Classic, SomaFM Drone Zone, Echoes of Bluemars, Cryosleep, Ambient Sleeping Pill). On the Favorites tab, r removes a favorite.
  • Rolling desktop updates from now on: installed systems pull theme / Swirl / SPO package fixes with sudo sweetpotatos-update (GitHub [sweetpotatos] channel). New Harvest ISOs are for fresh installs only — you no longer need a new point-release ISO just to stay current on the desktop.
  • Durable user overrides at ~/.config/swirl/config.d/user (loaded last; never overwritten by updates). Put custom binds and rules there; reload with Mod+Shift+c. See the project home page for a short guide.

Second Harvest

ISO Sweetpotatos_2026.09_Second_Harvest.iso · Files folder 2026.09_Second_Harvest

  • Added Spore (web radio + local music, Mod+r) and LocalSend (nearby sharing); replaced tera and Audacious.
  • Workspace navigation polish: restore Mod+Up / Mod+Down, plus Mod+Ctrl+Up / Mod+Ctrl+Down to move windows between workspaces.

First Harvest

ISO Sweetpotatos_2026.08_First_Harvest.iso · Files folder 2026.08_First_Harvest

  • First stable Harvest ISO (left the earlier BETA branding).
  • Live graphical session: Swirl compositor + SweetPotato theme under ~/.config/swirl/.
  • Calamares installer on the live desktop; installed systems use GRUB and Ly (Swirl session).
  • Default stack highlights: foot terminal, Shelly + yay, waypaper wallpapers, nwg-displays for monitors.
  • Session polish: Ly password focus, login tips, Bluetooth and power-profiles enabled, lid-close suspend, live Calamares keyboard sync to Swirl.
