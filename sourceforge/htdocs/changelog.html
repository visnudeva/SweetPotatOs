Third Harvest

Planned release 1 October 2026 · ISO Sweetpotatos_2026.10_Third_Harvest.iso · Files folder 2026.10_Third_Harvest

  • Tuber replaced Transmission for torrents (Mod+t) — light terminal BitTorrent client; magnet clicks hand off to the open session. Existing installs pick it up with sweetpotatos-update once the package is on the channel (Transmission is replaced).
  • Brave Origin became the default browser (Mod+w), replacing Firefox on new installs.
  • Mod+Tab workspace overview (all desktops); hold Super and drag windows between them. Plain click zooms back in.
  • Mod+Shift+Tab overview of windows on the current desktop.
  • Mod+? floating keybind cheatsheet (toggle), with a login tip that points at it every session.
  • Mod+a floating toggle.
  • Mod+Escape (same as Mod+o) power off.
  • Mod+Up / Mod+Down follow the visual stack (higher workspaces sit below).
  • Default wallpaper is SPixelBG; UsefulBinds / BindsBG are no longer shipped as defaults.
  • Rolling desktop updates from now on: installed systems pull theme / Swirl / SPO package fixes with sudo sweetpotatos-update (GitHub [sweetpotatos] channel). New Harvest ISOs are for fresh installs and marketing — you no longer need a new point-release ISO just to stay current on the desktop.
  • Durable user overrides at ~/.config/swirl/config.d/user (loaded last; never overwritten by updates). Put custom binds and rules there; reload with Mod+Shift+c. See the project home page for a short guide.

Second Harvest

ISO Sweetpotatos_2026.09_Second_Harvest.iso · Files folder 2026.09_Second_Harvest

  • Added Spore (web radio + local music, Mod+r) and LocalSend (nearby sharing); replaced tera and Audacious.
  • Workspace navigation polish: restore Mod+Up / Mod+Down, plus Mod+Ctrl+Up / Mod+Ctrl+Down to move windows between workspaces.

First Harvest

ISO Sweetpotatos_2026.08_First_Harvest.iso · Files folder 2026.08_First_Harvest

  • First stable Harvest ISO (left the earlier BETA branding).
  • Live graphical session: Swirl compositor + SweetPotato theme under ~/.config/swirl/.
  • Calamares installer on the live desktop; installed systems use GRUB and Ly (Swirl session).
  • Default stack highlights: foot terminal, Shelly + yay, waypaper wallpapers, nwg-displays for monitors.
  • Session polish: Ly password focus, login tips, Bluetooth and power-profiles enabled, lid-close suspend, live Calamares keyboard sync to Swirl.
