Keybinds

Mod is the Super / Windows key. On the desktop, Mod+? opens this same list.

Resize mode

After Mod+Shift+r:

KeyAction
h j k l or arrowsResize focused window
Enter / EscLeave resize mode

Your own binds

Edit ~/.config/swirl/config.d/user, then Mod+Shift+c. That file survives updates, and later binds win over the defaults. See custom Swirl config on the home page.

While the on-screen cheatsheet is open, w opens this website.
