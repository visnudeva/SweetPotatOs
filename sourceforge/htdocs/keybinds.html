After Mod+Shift+r:

KeyAction

Customize

Edit ~/.config/swirl/config.d/user, then Mod+Shift+c (survives updates; later binds win over defaults). See custom Swirl config on the home page.

Desktop / package updates

CommandNote
sudo sweetpotatos-updateUpdate the desktop
sweetpotatos-pruningReset shipped desktop config after experiments go wrong (keeps config.d/user and kanshi; clears user_edits)

A notice appears once a week when updates are ready. After an update, a note says what changed. Run pruning as your user, then Mod+Shift+c if Swirl did not reload.
